
# Telegram Music Remover Bot

A Telegram bot that separates human vocals from background music in videos using AI.

## Features

- Receive videos through Telegram.
- Remove background music while keeping vocals.
- Extract background music as MP3.
- Return two separate files.

## Technologies

- Python
- Telegram Bot API
- Demucs AI
- FFmpeg

## Installation

1. Install Python.
2. Install FFmpeg.
3. Install dependencies:

   pip install -r requirements.txt

4. Create a .env file.
5. Add BOT_TOKEN and ADMIN_ID.

## Run

python bot.py
